# 背诵规划表

基于艾宾浩斯遗忘曲线的纯前端背诵复习工具。录入条目和首次背诵信息后，自动生成第 2、3、5、8、14…… 天的复习计划；每天按科目分组列出该背的条目和建议用时，支持打印或导出 PDF。

界面为简单的平面风，无第三方依赖，数据保存在浏览器本地。

## 快速开始

1. 直接双击 `index.html`，用 Edge 或 Chrome 打开即可（`file://` 下也能正常保存数据）。
2. 首次使用：进入「科目设置」添加科目 → 进入「条目管理」添加条目。
3. 每天打开「今日复习」，按科目分组从上往下背诵，点每行末尾的圆圈标记完成。
4. 数据只保存在当前浏览器的 localStorage 中，换浏览器、换设备或清理浏览数据都会丢失，建议定期在「数据备份」里导出 JSON。
5. 想快速看效果：进入「数据备份」→「载入示例数据」。

如果希望通过本地服务器访问（可选）：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 功能

### 今日复习

- 按科目分组，单列竖向排列；同科目的条目排在一起。
- 每个科目组用细边框包起来，组头只标「科目名 + 该组建议用时合计」，组内条目不再重复科目标签。
- 条目从上往下排，排到一页底部再开第二页；一个科目组跨页时，下一页的组头标「（续）」。
- 每条显示建议用时，逾期条目会标注逾期天数。
- 点行末圆圈标记完成：条目从待复习清单移除，进入下方「今日已完成」折叠区，可撤销。
- 可切换查看日期，默认今天；查看未来日期时不能提前标记完成。
- 打印 / 导出 PDF：A4 纵向，单列分组，条目多时自动分页；已完成的条目不打印。
- 从任意页面按 Ctrl+P 都只打印今日清单（打印前会自动刷新数据）。

### 条目管理

- 按条目名或科目搜索，按科目筛选，按名称 / 首次日期 / 下次复习 / 添加时间排序。
- 查看详情：完整复习计划、每轮日期、建议用时、完成状态；可以补记完成或撤销。
- 编辑条目名、科目、首次背诵日期、首次记忆用时；删除条目（连带复习记录）。

### 科目设置

- 新增、改名、改颜色、停用、恢复、删除科目。
- 标签颜色支持 10 种预设色，也可以用系统取色器选择任意自定义颜色；标签文字会自动选深色或白色，保证可读。
- 停用科目不会影响已添加的条目，只是新条目不能再选择它；有引用的科目不能直接删除，只能停用。
- 科目改名或改色会同步到所有使用该科目的条目、今日复习组头和已完成列表。

### 数据备份

- 导出 JSON 备份、导入 JSON（覆盖当前数据）、载入示例数据、清空全部数据。
- 显示条目数、科目数、累计复习次数、今日待复习数。
- 内置复习规则说明。

## 复习算法

- 首次背诵当天记为第 1 天。
- 第 n 次背诵安排在第 `1.7^(n-1)` 天，天数四舍五入，也就是第 2、3、5、8、14、24、41…… 天。
- 下一次是第 1684 天（约 4.6 年后），已经超过 4 年上限，所以最多安排到第 990 天（约 2.7 年），共 14 次背诵。
- 第 n 次的建议用时 = 首次记忆用时 × `n^(-1/2)`，也就是首次用时除以 √n。
- 首次背诵视为已完成，从第 2 次开始进入今日清单。
- 逾期未完成的复习会一直保留在清单里，并标注逾期天数；完成当前轮后，下一轮才会出现。

以首次用时 15 分钟为例：

| 背诵次数 | 安排日期 | 建议用时 |
| --- | --- | --- |
| 第 1 次 | 首次当天 | 15 分钟 |
| 第 2 次 | 第 2 天 | 10.6 分钟 |
| 第 3 次 | 第 3 天 | 8.7 分钟 |
| 第 4 次 | 第 5 天 | 7.5 分钟 |
| 第 5 次 | 第 8 天 | 6.7 分钟 |
| 第 14 次 | 第 990 天 | 4.0 分钟 |

## 打印说明

- 使用 A4 纵向，页边距为 0，纸张内留白约 10–11mm。
- 单列排版，按科目分组；每个科目组带边框，组头标注科目名和该组建议用时。
- 每页大约 26–32 条，具体取决于科目组数量（组头、边框和组间距也占空间）；条目多时自动分页。
- 单个科目组在当前页放不下时，会拆到下一页，并在下一页组头标「（续）」。
- 在浏览器打印对话框里选「另存为 PDF」即可导出 PDF。
- 科目标签颜色通过 `print-color-adjust: exact` 保留；若打印预览里标签没有底色，请在打印设置中开启「背景图形」。
- 打印输出只包含待复习条目、科目组、日期、建议用时和页码；完成按钮、工具栏、已完成区不会打印。

## 文件结构

```text

```

## 数据格式

localStorage 键名：`beisong-plan-v1`

```json
{
  "version": 1,
  "subjects": [
    {
      "id": "s1",
      "name": "英语",
      "color": "#d9e7f2",
      "archived": false,
      "createdAt": "2026-10-25T04:00:00.000Z"
    }
  ],
  "entries": [
    {
      "id": "e1",
      "name": "单词 Unit 1",
      "subjectId": "s1",
      "firstDate": "2026-10-24",
      "firstMinutes": 20,
      "done": { "2": "2026-10-25" },
      "createdAt": "2026-10-25T04:00:00.000Z"
    }
  ],
  "settings": { "cols": 3 }
}
```

- `color` 是 6 位十六进制颜色，如 `#d9e7f2`。
- 旧版本备份中的数字颜色索引（0–9）会在加载或导入时自动转换成对应预设色。
- `settings.cols` 是旧版本遗留的栏数设置，当前版本改为单列分组排版后不再使用。
- `done` 的键是背诵次数 n（从 2 开始），值是实际完成日期。
- 导入备份时会做结构校验和字段规范化。

## 可调整项

- 增长底数：`app.js` 中的 `SESSION_BASE = 1.7`。
- 4 年上限：`MAX_SPAN_DAYS = 4 * 365`。
- 每页容量：`PAGE_UNITS = 34`（行单位）；每个科目组的组头/边框/间距占 `GROUP_OVERHEAD = 2`。
- 预设色板：`PRESET_COLORS` 数组。
- 建议用时公式：`buildPlan` 中的 `entry.firstMinutes / Math.sqrt(n)`。

## 注意事项

- 修改首次背诵日期或首次用时会按新数据重算后续复习日期；已完成的复习记录会保留，但日期可能和新计划不完全对应。
- 首次背诵日期不能晚于今天。
- 删除浏览器站点数据会清空全部内容，请定期导出备份。
- 推荐使用最新版 Edge / Chrome；手机端可以使用，窄屏会自动变为单列布局，打印仍按 A4 排版。
